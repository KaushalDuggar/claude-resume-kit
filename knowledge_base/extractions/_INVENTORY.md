# Extraction Inventory

> Updated automatically by `/setup-extract` (papers) and `/setup-extract-experience` (work experience). You can also edit manually.

## How to use

1. Papers: run `/setup-extract path/to/paper.pdf` for each paper
2. Work experience: run `/setup-extract-experience notes/<Org>.md` for each position
3. Each extraction creates a file in this directory
4. After all extractions, run `/setup-build-kb` to synthesize into experience files, bundles, etc.
